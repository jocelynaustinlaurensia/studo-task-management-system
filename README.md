STUDO — Student Task Organizer (Web App, SRS & PMR)
STUDO merupakan aplikasi manajemen tugas akademik berbasis web yang dirancang untuk membantu mahasiswa mengorganisasi tugas perkuliahan, memantau tenggat waktu (deadline), dan mengelola jadwal melalui tampilan kalender.
Repositori ini memuat implementasi kode sumber lengkap (Full-stack) serta artefak dokumentasi rekayasa perangkat lunak berupa Software Requirements Specification (SRS) dan Project Management Report (PMR).

Dokumen Laporan
- Berkas Laporan: `LAPORAN SISTEM MANAJEMEN APLIKASI STUDO.pdf`
- Mata Kuliah: Software Development

Tim Pengembang & Pembagian Peran
Proyek ini dikembangkan secara kolaboratif oleh Kelompok 4:
  - Penyusunan Software Requirements Specification (Bab 1: Pendahuluan, Deskripsi Umum Sistem, Kebutuhan Antarmuka Eksternal, Context Diagram)
  - Penyusunan Project Management Report (Bab 2: Work Breakdown Structure (WBS), Gantt Chart, PERT/CPM Critical Path Method, Function Point Estimation, Estimasi Biaya & Tenaga Kerja, RMMM Plan)
  - Analisis & Perancangan Diagram UML Lanjutan (DFD Level 0–5, Use Case Diagram & Skenario, Activity Diagram, Class Diagram, ERD, dan Sequence Diagram)
  - Implementasi Kode Aplikasi STUDO & Pengembangan Basis Data
  - Perancangan UI/UX (Figma), Pembuatan Prototipe Interaktif, dan Pengujian Sistem

Cakupan Analisis & Manajemen Proyek
1. Analisis Kebutuhan Sistem:
   - Pemodelan Data & Proses: Context Diagram, Data Flow Diagram (DFD Level 0 hingga Level 5).
   - Pemodelan UML: Use Case Diagram, Activity Diagram Swimlane, Class Diagram, Sequence Diagram, dan Communication Diagram.
   - Pemodelan Basis Data: Entity Relationship Diagram (ERD).
2. Manajemen Proyek Perangkat Lunak:
   - Work Breakdown Structure (WBS): Dekomposisi tugas berbasis fase SDLC menggunakan ProjectLibre.
   - Penjadwalan Proyek: Gantt Chart dan PERT Network Analysis (Critical Path Method & Slack Calculation).
   - Estimasi Usaha & Biaya: Function Point (FP) dengan Value Adjustment Factors (VAF), estimasi waktu pengerjaan (effort), dan anggaran biaya proyek.
   - RMMM Plan: Rencana mitigasi, pemantauan, dan manajemen risiko sistem.

Fitur Utama Aplikasi
- Autentikasi Pengguna: Sistem verifikasi login/logout mahasiswa.
- Home Dashboard: Ringkasan capaian belajar harian, tugas aktif, dan tenggat waktu terdekat.
- Assignment Management: Operasi CRUD tugas kuliah dengan atribut nama tugas, mata kuliah, dosen, dan tanggal pengumpulan.
- Activity Tracker: Pencatatan otomatis riwayat penambahan, modifikasi, dan penghapusan tugas.
- Interactive Calendar: Visualisasi agenda dan batas waktu tugas berbasis kalender.
